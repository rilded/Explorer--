# Explorer--  
лёгкий двухпанельный файловый менеджер для Windows (подходит для WinPE)  
<pre>
Работа с файлами  
    Одна или две панели (переключается), дерево дисков и папок слева, закладки.  
    Копирование, вырезание, вставка, перенос и удаление в фоне: окно прогресса со скоростью и оставшимся временем, отмена, интерфейс не замирает.  
    Перетаскивание файлов мышью в панель  
    Архивы (zip, tar, tgz, tar.gz/bz2/xz): двойной клик открывает архив как папку (содержимое распаковывается во временную папку) и есть "Распаковать здесь".  
    Поиск файлов  
Удобства  
    Список обновляется сам при изменениях на диске.  
    Очень большие папки (тысячи файлов) открываются сразу благодаря виртуальному списку.  
    Папки и диски загружаются в фоне — можно пользоваться программой во время загрузки, зависшие диски не блокируют окно.  
    Колонки (Имя, Размер, Тип, Изменён) тянутся мышью, сортировка по клику.  
Процессы и ошибки  
    Если файл занят, программа определяет процесс и завершает его  
    Занятые файлы подсвечиваются в списке.  
    В WinPE работает без psutil (встроенный запасной слой на ctypes).  
  
Горячие клавиши
    Ctrl+C / Ctrl+X / Ctrl+V	копировать / вырезать / вставить
    Delete удалить
    F2 переименовать
    F5 обновить
    Ctrl+A	выделить всё
    Ctrl+F, F3	поиск
    Alt+Enter	свойства
    Двойной клик	открыть папку / файл / архив
    Правая кнопка	контекстное меню
